# Codex Daily Token Widget

一个仅在本机运行、始终置顶的 Windows Codex 每日 Token 用量悬浮窗。

![Node.js](https://img.shields.io/badge/Node.js-22.13%2B-5FA04E)
![Privacy](https://img.shields.io/badge/data-local--only-6EE7A5)

## 功能

- 原生 Windows 悬浮小窗，无需打开浏览器
- 默认使用约 260×68 的极简信息条，适合贴在论文或编辑器边缘
- 今日用量、较昨日变化和近 7 天用量
- 七日迷你柱状图与今日 Token 构成
- 始终置顶、可拖动，也可以临时取消置顶
- 区分缓存输入、非缓存输入、输出和推理输出
- 网页看板按任务用量排行，可展开查看每轮输入、缓存、输出和总量
- 自动识别高消耗轮次，大量任务和轮次采用分批显示
- 原生完整悬浮面板提供“概览 / 任务”双视图，可直接查看任务排行和每轮用量
- 任务轮次按需加载，使用鼠标滚轮浏览，不会拖慢日常刷新
- 任务编号后显示与 Codex 项目侧边栏完全一致的聊天名称，每轮显示经过过滤的用户提示词摘要
- 支持按任务名或任意一轮用户提示词搜索任务
- 后台子任务自动归并到上级用户任务，不再显示大量同名内部任务
- 可将任一任务设为“小窗关注”，在极简条中逐轮查看 Token，并用滚轮或左右箭头切换
- 自动读取活动会话与归档会话，按会话 ID 去重
- 日志扫描在独立 Worker 中执行，健康检查不会被大文件扫描阻塞
- 每 5 分钟自动刷新，并将最近一次聚合摘要缓存在本机
- 请求超时、服务退出或挂起时自动诊断、重启并重试
- 自动识别当前用户目录和 `CODEX_HOME`，默认端口被占用时自动选择其他本地端口
- 只绑定 `127.0.0.1`，不需要账号、API Key 或网络请求
- 不上传提示词、回复、项目路径或凭据；提示词摘要仅按用户选择在本机界面显示

## Windows 快速使用

推荐从 GitHub Actions 或 Release 下载 `CodexTokenWidget-windows-x64.zip`。压缩包已经包含运行环境，无需安装 Node.js，也无需填写服务器地址、端口、账号或配置文件；解压整个文件夹后双击：

```text
CodexTokenWidget.exe
```

程序默认以极简信息条显示在桌面右上角，每 5 分钟自动刷新，只保留今日用量、同步状态、展开和隐藏。点击 `+` 或双击小窗可展开完整视图；顶部“概览 / 任务”可切换统计内容。任务页搜索框支持任务名称和提示词关键词，停顿约半秒或按 Enter 开始搜索，按 Escape 清空。打开任一结果并点击“小窗关注”，收起窗口即可切换到该任务；滚轮或左右箭头切换轮次，点击数字左侧可在任务轮次与今日总量之间切换。托盘菜单“**小窗显示**”也可以选择显示模式。

再次双击程序不会产生第二个实例，而会直接唤出现有悬浮窗。Windows 关机或注销时程序会正常退出；如果挂件异常结束，本地统计服务也会检测父进程并自行关闭。

从源码运行需要 Node.js 22.13 或更新版本，也可以在终端中运行：

```powershell
npm run widget
```

悬浮窗会在需要时静默启动本地统计服务，并在退出时结束自己启动的服务。数据不会离开电脑。

如果本地统计服务意外退出，悬浮窗会自动检测、重启并刷新数据，不需要手动重开程序。界面会显示具体的错误类型；完整诊断记录保存在：

```text
%LOCALAPPDATA%\CodexTokenWidget\widget.log
```

也可以右键系统托盘中的 Codex Token 图标，选择 **打开诊断日志**。日志达到 1 MB 后自动轮换，只保留当前文件和上一份日志。写入前会将用户目录和程序目录替换为 `%USERPROFILE%`、`%APPDIR%`，不会记录提示词或回复内容。

## 可选网页仪表盘

项目仍保留完整网页看板，运行：

```powershell
npm start
```

再访问 `http://127.0.0.1:4817`。任务使用哈希派生的本地编号（不是加密或强匿名化），不返回原始会话 ID、轮次 ID 或路径；任务标题和提示词摘要只通过回环地址在本机显示。需要停止时双击 `stop-dashboard.cmd`。

## 数据口径

程序优先读取 `CODEX_HOME`；未设置时自动使用当前 Windows 用户目录中的以下 `token_count` 事件：

```text
%USERPROFILE%\.codex\sessions\**\rollout-*.jsonl
%USERPROFILE%\.codex\archived_sessions\*.jsonl
```

优先使用 `last_token_usage`（单次模型调用用量）；旧日志只有 `total_token_usage` 时，按会话累计值求差，避免重复累计。新版日志通过 `task_started` 和 `task_complete` 边界，将一次对话轮次中的多次模型调用合并；缺少边界的旧记录会标为“未标记轮次”。缓存 Token 是输入 Token 的子集，因此总量使用日志中的 `total_tokens`，不会把缓存输入再次加到总量中。同一轮中的不同模型调用分别累加，仅去除相同事件和累计值未变化的重复通知。跨午夜的同一轮按本地日期拆为多个日内轮次段，任务范围总量与每日统计一致。

统计是本机 Codex 记录口径，不等同于 API 账单或订阅额度。

聚合缓存和诊断日志默认位于 `%LOCALAPPDATA%\CodexTokenWidget`，不会写入 Git 仓库。为支持离线快速查看，聚合缓存可能包含最长 240 字符的提示词摘要；不会缓存助手回复、工具输出或注入的环境上下文。环境变量 `CODEX_TOKEN_CACHE_DIR` 可以单独修改聚合缓存目录。


## 1.6.0 安全与性能说明

- 服务只监听回环地址，并验证 Host、Origin、浏览器来源信息和随机实例令牌。网页自动获取令牌，悬浮窗只连接自己启动的实例；不复用身份不明的端口服务。
- 这不是对同一 Windows 账户下恶意进程的隔离。能够读取你的本地文件或控制浏览器的程序仍可能读取缓存与令牌。
- 停止脚本仅向当前安装目录登记、身份匹配的服务发送认证关闭请求，不再按端口强杀进程。悬浮窗管理的服务请通过托盘“退出”关闭；旧版服务没有登记文件，需要在原启动终端或托盘退出。
- 缓存按数据目录、时区和格式版本隔离，保存真实统计时间；刷新失败明确显示旧缓存，不伪装成刚同步的数据。手动刷新立即检查日志。
- 单一增量解析器读取新增内容，处理半行 UTF-8、截断、同大小改写、活动/归档去重和删除；保存并压缩解析进度，重启后可以继续增量读取。假设正常日志采用追加写入；同时间戳、同大小的外部伪装改写无法仅靠文件属性识别。
- 缓存包含任务标题、最长 240 字符的用户提示词摘要、内部会话标识和去重检查点，不包含助手回复或工具输出。它不是脱敏数据；分享发布包时不要附带本地缓存。只提取用户文本不意味着敏感内容一定被过滤，请勿把本地摘要截图当作自动脱敏结果。
- 网页首次只请求 20 个任务摘要；展开后每次取 50 个轮次段。搜索索引、筛选和分页在 Worker 中处理。悬浮窗保留全量任务摘要和单任务详情接口。
- 缓存会在正常刷新时清理已不存在文件的内存检查点；旧格式磁盘缓存不会自动删除，可退出程序后自行清理 `usage-*.json*` 和旧 `usage-summary.json`，不要删除 `servers` 中仍在使用的实例登记。
- 首次统计仍需读取全部历史。约 10 GB 日志实测首次约 50–58 秒，含压缩缓存落盘的增量刷新约 2.4 秒，重启后约 4 秒（视硬盘和新增量变化）；内存缓存请求约 1 毫秒。冷启动请求上限为 180 秒，前端为 190 秒。界面保留旧数据并显示错误，不把读取失败显示为零。
- 不使用网络遥测、不上传会话，也不依赖 ripgrep。源码运行至少需要 Node.js 22.13；元数据数据库缺失或字段变化时使用会话索引/提示词标题回退，子任务归并可能不完整。

## 从源码构建悬浮窗

Windows 10/11 自带的 Windows PowerShell 5.1 即可编译，无需 Visual Studio：

```powershell
npm run build:widget
```

构建前请从托盘彻底退出正在运行的悬浮窗。构建结果为项目根目录下的 `CodexTokenWidget.exe`。构建脚本先编译临时文件，成功后才替换旧程序；如果旧文件正在使用，替换可能失败，但不会预先删除旧程序。启动与构建脚本使用仅对当前 PowerShell 进程生效的执行策略参数，不更改系统持久设置。

生成包含 Node.js、网页资源和 SHA-256 校验值的完整发布包：

```powershell
npm run package:windows
```

二进制不直接提交到仓库；GitHub Actions 会从公开源码重新编译，并在 `dist` 中生成 ZIP 和校验文件。

## 代码结构

- `Widget.cs`：窗口绘制、交互和本地服务生命周期
- `widget/Widget.Search.cs`：原生任务搜索控件与请求状态
- `widget/Widget.Models.cs`：原生任务和轮次数据模型
- `server.mjs`：仅绑定回环地址的本地 HTTP 服务与任务检索
- `src/usage.mjs`：日志解析、子任务归并、标题和 Token 聚合
- `scripts/package-windows.ps1`：生成无需配置的 Windows 完整包
